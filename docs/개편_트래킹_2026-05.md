- **D1 (P0) 토큰화**: C1·C2·C3 색을 `:root` 토큰으로 승격 후 App.css 치환. (전역 일관성)

- **D3 AI Studio(B6)**: finding 토큰 적용, 품질점수 막대 시각화, 인라인 style 제거.
- **D4 PetStage 잔여(A7)**: 먹이기 버튼 위계 정리.
- **D5 리서처 Dashboard/Surveys(B3·B4)**: KPI 차별화, 버튼 위계, 배너 일반화.
- **D6 패널 진입부(A1·A2·A4)**: Onboarding 뒤로가기, 로딩 표준화, radius 토큰.
- **D7 ResponseStage(A9)·PublishModal(B8)**: 버튼 일관성, 폼 오류 상태.
- **D8 (P1) `window.confirm` → 확인 모달(C4)**: 공용 ConfirmDialog 도입.
- **D9 검증·커밋**: 단계마다 lint/typecheck/build (백엔드 변경 시 test) 후 커밋.

> 각 단계 완료 시 위 표의 상태/반영 칸을 갱신한다.
