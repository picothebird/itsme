# 잇츠미 모바일 글래스모피즘 — 토큰 & 적용 설계

> 선행 문서: [`디자인조사_Material_Apple글래스.md`](./디자인조사_Material_Apple글래스.md)
> 대상 코드: `apps/frontend/src/App.css` (토큰: `.pm-root` / `:root[data-pm-theme='dark'] .pm-root`),
> `apps/frontend/src/features/PanelistMobile.tsx`

본 문서는 조사 결과를 **실제 CSS 토큰과 컴포넌트 매핑**으로 구체화한다.
목표: 화이트=화사한 글래스, 다크=세련된 애플 다크. 두 모드 모두 한 토큰 세트로 분기.

---

## 1. 현재 상태 진단

- 테마 토큰은 이미 잘 구조화됨: 라이트는 `.pm-root`, 다크는 `:root[data-pm-theme='dark'] .pm-root`에
  동일 토큰을 재정의(`--color-canvas`, `--color-surface`, `--color-ink` 등).
- 그러나 표면은 대부분 **불투명 단색**(`--color-surface: #fff` / `#1c1f26`)이라 "유리"가 아님.
- `backdrop-filter`는 탑바·일부 오버레이에만 산발적으로 사용 중. 토큰화되지 않아 일관성 없음.
- 설문 보기(`.pm-choice`)·리커트(`.pm-likert__dot`)·토스트는 평면 카드.

**개편 전략:** 기존 토큰을 건드리지 않고 **글래스 토큰 레이어를 추가**한 뒤,
표면 컴포넌트의 `background`를 글래스 토큰으로 교체한다. 분기는 토큰 한 곳에서만.

---

## 2. 추가할 글래스 토큰 (Single source of truth)

`.pm-root`(라이트)와 다크 셀렉터 양쪽에 동일 변수명으로 값만 다르게 정의.

### 2.1 라이트 (화사한 글래스)

```css
.pm-root {
  /* 배경: 유리가 비칠 "뒷면". 단색 대신 은은한 컬러 글로우 */
  --pm-bg-glow:
    radial-gradient(120% 90% at 0% 0%, rgba(86, 69, 212, 0.1) 0%, transparent 50%),
    radial-gradient(120% 90% at 100% 0%, rgba(49, 130, 246, 0.08) 0%, transparent 45%),
    radial-gradient(140% 120% at 50% 100%, rgba(255, 145, 180, 0.07) 0%, transparent 55%);

  --pm-glass-bg: rgba(255, 255, 255, 0.62);
  --pm-glass-bg-strong: rgba(255, 255, 255, 0.78); /* 시트·모달 */
  --pm-glass-blur: saturate(180%) blur(20px);
  --pm-glass-blur-strong: saturate(180%) blur(28px);
  --pm-glass-border: rgba(255, 255, 255, 0.7);
  --pm-glass-shadow: 0 8px 30px rgba(31, 28, 56, 0.1);
  --pm-glass-hi: inset 0 1px 0 rgba(255, 255, 255, 0.65);

  /* 선택/강조 유리 틴트 */
  --pm-glass-tint: rgba(86, 69, 212, 0.1);
}
```

### 2.2 다크 (세련된 애플 다크)

```css
:root[data-pm-theme='dark'] .pm-root {
  --pm-bg-glow:
    radial-gradient(120% 90% at 0% 0%, rgba(143, 128, 255, 0.16) 0%, transparent 50%),
    radial-gradient(120% 90% at 100% 0%, rgba(106, 166, 255, 0.12) 0%, transparent 45%),
    radial-gradient(140% 120% at 50% 100%, rgba(255, 120, 170, 0.08) 0%, transparent 55%);

  --pm-glass-bg: rgba(28, 31, 38, 0.58);
  --pm-glass-bg-strong: rgba(30, 33, 41, 0.78);
  --pm-glass-blur: saturate(150%) blur(22px);
  --pm-glass-blur-strong: saturate(150%) blur(30px);
  --pm-glass-border: rgba(255, 255, 255, 0.1);
  --pm-glass-shadow: 0 10px 36px rgba(0, 0, 0, 0.45);
  --pm-glass-hi: inset 0 1px 0 rgba(255, 255, 255, 0.08);

  --pm-glass-tint: rgba(143, 128, 255, 0.2);
}
```

### 2.3 재사용 유틸 (선택)

반복되는 유리 표면을 한 줄로:

```css
.pm-glass {
  background: var(--pm-glass-bg);
  backdrop-filter: var(--pm-glass-blur);
  -webkit-backdrop-filter: var(--pm-glass-blur);
  border: 1px solid var(--pm-glass-border);
  box-shadow: var(--pm-glass-shadow), var(--pm-glass-hi);
}
```

## 3. 컴포넌트 매핑 (어디에 유리를 입히나)

| 영역           | 클래스             | Elevation | 적용                                                  |
| -------------- | ------------------ | --------- | ----------------------------------------------------- |
| 앱 배경        | `.pm-root`         | 0         | `--pm-bg-glow`를 캔버스 위에 깔아 유리가 비칠 색 제공 |
| 상단바         | `.pm-topbar`       | 1         | 글래스 + 하단 헤어라인                                |
| 설문 보기 버튼 | `.pm-choice`       | 1         | 글래스 카드, 선택 시 `--pm-glass-tint`                |
| 리커트 버튼    | `.pm-likert__dot`  | 1         | 글래스 알약, 선택 시 컬러 틴트                        |
| 자유응답       | `.pm-textarea`     | 1         | 글래스 입력 필드                                      |
| 경고/토스트    | `.pm-toast`        | 1         | 글래스 + 의미색 틴트                                  |
| 바텀 시트      | `.pm-sheet__panel` | 2         | strong 글래스(blur 28px)                              |
| 바텀 내비      | `.pm-bottomnav`    | 1         | 글래스(스크롤 콘텐츠가 비침)                          |

**한 겹 원칙:** 글래스 표면 위에 또 글래스를 얹지 않는다.
예) 글래스 시트 내부의 버튼은 불투명/틴트로.

## 4. 접근성·성능 폴백

1. **투명도 민감 사용자 / 블러 미지원**

   ```css
   @media (prefers-reduced-transparency: reduce) {
     .pm-root {
       --pm-glass-bg: var(--color-surface);
       --pm-glass-blur: none;
     }
   }
   @supports not (backdrop-filter: blur(1px)) {
     .pm-root {
       --pm-glass-bg: var(--color-surface);
     }
   }
   ```

   → 블러가 빠지면 자동으로 불투명 표면으로 대체(가독성 보장).

2. **모션 민감**: 기존 `prefers-reduced-motion` 블록 유지. 유리 자체는 정적이라 추가 부담 없음.

3. **대비**: 본문 텍스트는 불투명 `--color-ink` 유지. 유리 위 12sp 이하 보조텍스트는
   `--color-ink-soft` 대신 한 단계 진한 톤 사용.

4. **성능**: `backdrop-filter`는 GPU 비용이 있다. 동시에 떠 있는 유리 표면을
   화면당 3~4개로 제한(배경/탑바/카드/시트). 리스트 아이템 다수에는 blur 대신
   반투명만 적용하거나 컨테이너 한 곳에만 blur.

---

## 5. 적용 순서 (구현 체크리스트)

1. `.pm-root` 라이트/다크에 글래스 토큰 + `--pm-bg-glow` 추가.
2. `.pm-root` 배경에 `--pm-bg-glow` 레이어 합성.
3. `.pm-glass` 유틸 정의.
4. 설문 컴포넌트(`.pm-choice`, `.pm-likert__dot`, `.pm-textarea`, `.pm-toast`) 글래스화.
5. 시트·탑바·바텀내비 글래스화(여력 시).
6. 폴백 미디어쿼리 추가.
7. 라이트/다크 양쪽 스크린샷 검증.
